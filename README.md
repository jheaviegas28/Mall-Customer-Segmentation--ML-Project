# Mall-Customer-Segmentation--ML-Project
Machine learning project on Mall Customer Segmentation

#Objective:
Analyze mall customer data to identify customer groups and predict customer behavior for targeted marketing.

#Techniques Used:
#K-Means Clustering:
Segmented customers into distinct groups based on features such as Age, Annual Income, and Spending Score.
#Decision Tree Classification:
Classified customers into spending categories and provided interpretable decision rules.
#Random Forest Classification:
Improved classification accuracy by combining multiple decision trees and reducing overfitting.
#Linear Regression:
Predicted customer spending score based on demographic and income-related features.

#Workflow:

#Data preprocessing and visualization.
#Customer segmentation using K-Means (Elbow Method used to find optimal clusters).
#Training and testing of Decision Tree and Random Forest models.
#Spending score prediction using Linear Regression.
#Model evaluation using Accuracy, Confusion Matrix, MAE, MSE, RMSE, and R² Score.

#Business Benefits:

#Targeted Marketing: Enables personalized promotions for different customer segments.
#Customer Retention: Identifies valuable customers and helps design loyalty programs.
#Revenue Growth: Focuses marketing efforts on high-spending customer groups.
#Resource Optimization: Helps allocate advertising budgets more effectively.
#Better Decision-Making: Provides data-driven insights into customer purchasing behavior.
#Improved Customer Experience: Tailors products and services according to customer preferences.

#Outcome:
The project successfully identified customer segments, predicted spending behavior, and demonstrated the effectiveness of clustering, classification, and regression techniques for customer analytics and personalized marketing strategies.
